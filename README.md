# Sudoku

Fresh puzzles at three levels, with notes and mistake checking.

Fill the grid so every row, column and 3×3 box has the digits 1 to 9. Every puzzle has exactly one solution.

- Easy, Medium and Hard
- Pencil marks, undo, and optional mistake highlighting
- Keyboard or tap to play

## Run it

Open `app/index.html` in a browser. There's no build step and no dependencies: plain HTML, CSS and JavaScript.

On AI Index it runs in the browser with **Run here** (Offline). `aiindex.json` tells AI Index which
folder to serve; its token links this repo to the listing.
